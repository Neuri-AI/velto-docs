**Level: Intermediate. Prerequisites:** [FocusBoard 04](/projects/focusboard-stage-04-dynamic-list) and [Flex](/layout/flex).

Stage 05 puts task rows in a scrolling Flex layout and includes a verified `Grid` construction. Run `velto/examples/documentation/focusboard/stage-05-layout/main.py`.

The headless SFLE contract requires an explicit Flex root and a single Flex child inside `Scroll`; Grid native content-root rules are renderer-specific. Read [Grid](/layout/grid) before embedding it in a native screen.
