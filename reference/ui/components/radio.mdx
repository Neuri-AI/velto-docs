---
title: Radio
description: Render one selectable radio option.
---

```python
from velto.ui import Radio
```

`Radio(value, label="", enabled=True, key=None, ref=None, **props)` is a leaf option. Use it within `RadioGroup` for controlled selection.

```python
Radio("today", label="Today")
```

See [RadioGroup](/reference/ui/components/radio-group) for selection events.
