---
title: Scroll
description: Render a scrollable container.
---

```python
from velto.ui import Scroll
```

`Scroll(*children, direction="vertical", content_direction="vertical", scrollbar="auto", width=None, height=None, spacing=0, padding=0, enabled=True, key=None, ref=None, **props)` accepts multiple children.

```python
Scroll(*rows, height=320, spacing=8, padding=12)
```

Available scrollbar modes and nested scrolling behavior depend on the renderer.
