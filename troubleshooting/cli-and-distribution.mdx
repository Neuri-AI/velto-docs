title: CLI and distribution
description: Diagnose Qyro CLI and generated-project workflows.
---

The available command is `qyro`, not a façade command. Run `qyro --help` in the project environment.

Generated-project distribution instructions are currently blocked: the boilerplate imports `velto` without declaring it and its Python range can exceed Velto's declared range. The required product correction is recorded locally; it is not silently worked around in the docs.
