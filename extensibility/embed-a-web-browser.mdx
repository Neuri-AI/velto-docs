title: "Embed a web browser"
description: "Use a PySide6 QWebEngineView with Native reactive props."
---

`QWebEngineView` is a Qt widget. Velto mounts it through `Native`;
it does not convert it to Tkinter or Kivy.

## 1. Install matching dependencies

```bash
python -m pip install "velto[pyside6]" PySide6-Addons
```

Use the compatible WebEngine distribution for your binding and ensure
the platform-specific WebEngine runtime is packaged with your app.

## 2. Embed the widget without reactive data

```python
from PySide6.QtWebEngineWidgets import QWebEngineView
```

```jsx
<Native widget={QWebEngineView}
        width="100%" height="100vh" key="browser" />
```

No adapter is required merely to embed a native widget.

## 3. Navigate reactively using a custom class

```python
from PySide6.QtCore import QUrl
from PySide6.QtWebEngineWidgets import QWebEngineView

class Browser(QWebEngineView):
    def update_props(self, props, changed):
        if "url" in changed:
            value = props["url"].strip()
            if not value:
                return
            if not value.startswith(("http://", "https://")):
                value = "https://" + value
            self.setUrl(QUrl(value))
```

```jsx
<Native widget={Browser}
        props={{"url": current_url}}
        width="100%" height="100vh" key="browser" />
```

`current_url` can be maintained through `use_state`. The widget stays mounted,
and only changing the URL causes navigation.

## 4. Use the original Qt class with native_adapter

```python
from velto.ui import native_adapter

@native_adapter(QWebEngineView)
def update_browser(widget, props, changed):
    if "url" in changed:
        widget.setUrl(QUrl(props["url"]))
```

The same `<Native widget={QWebEngineView} props={{"url": current_url}} />`
is now controlled without subclassing.

The `props` mapping does not infer `set_url()`, `setUrl()` or any arbitrary
setter; the class/adapter is responsible for native behavior.

## 5. Events, lifecycle and portability

Use `signals` to subscribe to Qt signals such as `loadFinished`.
Match the runtime's Qt binding and verify WebEngine packaging when frozen.
Qt widgets are not accepted by the Kivy or Tkinter renderers.

See [Native component reference](/reference/ui/components/native).
