---
title: "Build a native chart"
description: "Integrate PyQtGraph and update data reactively without remounting."
---

PyQtGraph supplies the chart renderer. Velto supplies PSX Markup,
Cinnamon layout, and the reactive `Native` contract.

## 1. Install PySide6 and PyQtGraph

```bash
python -m pip install "velto[pyside6]" pyqtgraph numpy
```

Ensure PyQtGraph selects the same Qt binding as Velto.

## 2. Register a reusable chart adapter

```python
import pyqtgraph as pg
from velto.ui import native_adapter

@native_adapter(pg.PlotWidget)
def update_chart(widget, props, changed):
    if not hasattr(widget, "_curve"):
        widget._curve = widget.plot(pen=pg.mkPen("#8B5CF6", width=2))

    if "data" in changed:
        widget._curve.setData(props["data"])
```

This adapter is registered once. It receives the widget instance,
all reactive props and a `frozenset` containing only changed keys.

## 3. Use the chart from PSX Markup

```jsx
<Native
    widget={pg.PlotWidget}
    kwargs={{"background": "#151515"}}
    props={{"data": cpu_values}}
    width="100%"
    height="400px"
    key="chart"
/>
```

`kwargs` is constructor-only configuration. `props` is reactive:
for example, `cpu_values` may be supplied by `use_state`. Replacing
`cpu_values` with a new array causes `changed` to include `data`.

No `PlotWidget` is recreated when data changes. The adapter keeps one
curve and calls `setData()` only for changed `data` values.

## 4. Using a class you own

You can skip the decorator by providing the same contract in your class:

```python
class Chart(pg.PlotWidget):
    def __init__(self):
        super().__init__()
        self.curve = self.plot()

    def update_props(self, props, changed):
        if "data" in changed:
            self.curve.setData(props["data"])
```

```jsx
<Native widget={Chart}
        props={{"data": cpu_values}}
        width="100%" height="400px" />
```

## 5. Performance and constraints

Reactive updates execute in the renderer's UI thread. `changed` avoids
redundant native operations; supply a **new** array or object when its content
changes because in-place mutations are not detected. The graph's width and
height belong to Cinnamon and do not call arbitrary widget setters.

Test using the actual native renderer on your OS; conceptual examples
do not constitute offscreen graphical certification.
