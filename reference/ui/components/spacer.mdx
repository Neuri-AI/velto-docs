---
title: Spacer
description: Add flexible space in a layout.
---

```python
from velto.ui import Spacer
```

`Spacer(*, key=None, ref=None, **props)` is a leaf layout item. Supply supported sizing props for the active layout renderer.

```python
Flex(Text("FocusBoard"), Spacer(), Button("Add"))
```

See [sizing, spacing, and alignment](/layout/sizing-spacing-and-alignment).
