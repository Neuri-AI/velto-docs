---
title: ProgressBar
description: Render determinate or indeterminate progress.
---

```python
from velto.ui import ProgressBar
```

`ProgressBar(value=0, min=0, max=100, indeterminate=False, orientation="horizontal", enabled=True, key=None, ref=None, **props)` is a leaf component.

```python
ProgressBar(value=completed, max=total)
```

The native backend controls animation and presentation of indeterminate progress.
